# 洛雪音乐（LX Music）音源订阅

本目录整理常用、可在线导入的洛雪自定义音源地址。  
洛雪使用的是 **`.js` 音源脚本**（不是 TVBox 那种 JSON），在软件里「在线导入」即可。

> 音源由社区维护，可用性会随时间变化；若某个导入失败，换列表里其他源即可。

---

## 使用方法

### 电脑端
1. 打开洛雪音乐 → **设置** → **基本设置**
2. 找到 **音乐来源 / 自定义源** → **自定义源管理**
3. 选择 **在线导入**
4. 粘贴下面任意一条链接 → 确认
5. 出现「初始化成功」后勾选启用该源

### 手机端
1. 左上角菜单 → **设置**
2. **自定义源管理** → **导入** → **在线导入**
3. 粘贴链接 → 确认并启用

建议同时导入 **2～3 个源**，播放时自动切换更稳。

## 说明

- 音源脚本由社区公开维护（如 [pdone/lx-music-source](https://github.com/pdone/lx-music-source)），本仓库只做整理与备份入口。
- 无法从零“写一个永久可用的官方级音源”：需要对接各平台接口，且接口经常变更。
- 仅供个人学习与试听，请遵守当地法律法规与平台服务条款。
- 若全部失效，可到 `pdone/lx-music-source` 仓库查看最新 `latest.js` 路径。
